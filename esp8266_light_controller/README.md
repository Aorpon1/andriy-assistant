# ESP8266 — WiFi світло-контролер з веб-мордою

Плата ESP8266 сама роздає WiFi. Ти підключаєшся телефоном, заходиш у браузер і
керуєш світлом: **вкл/викл**, **повзунок яскравості**, **строб** + швидкість строба.
Світло за замовчуванням **вимкнене** і вмикається тільки з веб-морди.

---

## 1. Що тобі потрібно

- Плата **ESP8266** (NodeMCU або Wemos D1 mini)
- USB-кабель (обов'язково з даними, не тільки для зарядки)
- Комп'ютер з **Arduino IDE** (безкоштовна: https://www.arduino.cc/en/software)
- Світлодіод + резистор **220–330 Ом** (для тесту) АБО MOSFET-модуль для потужного світла

---

## 2. Одноразове налаштування Arduino IDE під ESP8266

Це робиться лише раз.

1. Відкрий Arduino IDE → меню **File → Preferences**.
2. У поле **Additional Boards Manager URLs** встав:
   ```
   http://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
   Натисни **OK**.
3. Меню **Tools → Board → Boards Manager**.
4. У пошуку набери `esp8266`, знайди **"esp8266 by ESP8266 Community"**, натисни **Install**.
5. Тепер обери свою плату: **Tools → Board → ESP8266 Boards → NodeMCU 1.0 (ESP-12E Module)**
   (або **LOLIN(WeMos) D1 mini**, якщо у тебе Wemos).

> Servo, ESP-NOW тощо тут не потрібні — цей скетч використовує тільки вбудовані
> бібліотеки `ESP8266WiFi` та `ESP8266WebServer`, які ставляться разом із платою.

---

## 3. Завантаження скетча на плату

1. Відкрий файл **`esp8266_light_controller.ino`** в Arduino IDE
   (папка і файл мусять називатись однаково — так вимагає Arduino).
2. Підключи плату кабелем до USB.
3. Обери порт: **Tools → Port** → вибери той, що з'явився після підключення
   (Windows: `COMx`, Mac: `/dev/cu.usbserial...` або `/dev/cu.wchusbserial...`).
4. Натисни кнопку **Upload** (стрілка вправо ➜) угорі зліва.
5. Дочекайся напису **"Done uploading"** внизу.

> **Якщо порт не з'являється** — швидше за все потрібен драйвер USB-чіпа:
> CH340 (більшість дешевих плат) або CP2102. Загугли "CH340 driver" під свою ОС.

---

## 4. Як користуватись

1. На телефоні відкрий **Налаштування → WiFi**.
2. Підключись до мережі **`FPV-Light`**, пароль **`12345678`**.
   (Інтернету в цій мережі немає — це нормально, телефон може лаятись.)
3. Відкрий будь-який браузер і введи адресу:
   ```
   http://192.168.4.1
   ```
4. З'явиться панель керування:
   - **УВІМКНУТИ / ВИМКНУТИ** — загальне світло
   - **Яскравість** — повзунок 0–100%
   - **СТРОБ** — вмикає блимання
   - **Швидкість строба** — від 1 до 20 спалахів за секунду

Стан зберігається на самій платі, тому нова вкладка/телефон побачать актуальні значення.

---

## 5. Куди підключати світло (пін D7)

Пін світла — **D7 (GPIO13)**.

- **Маленький світлодіод для тесту:**
  `D7 → резистор 220–330 Ом → (+) ніжка LED`, а `(−) ніжка LED → GND` плати.
- **Потужне світло / стрічка:** пін D7 керує **затвором MOSFET** (напр. IRLZ44N або
  готовий MOSFET-модуль), а вже MOSFET вмикає окреме живлення світла. Логіка коду
  та сама. **Не підключай потужне світло напряму до піна — спалиш плату.**

> Якщо світло горить "навпаки" (яскраво при вимкненні) — у скетчі постав
> `const bool LED_INVERT = true;`

---

## 6. Як змінити налаштування

Все зверху файла `.ino`:

| Що змінити | Рядок у коді |
|---|---|
| Назву WiFi | `const char* AP_SSID = "FPV-Light";` |
| Пароль WiFi (мін. 8 символів, або `""` без пароля) | `const char* AP_PASS = "12345678";` |
| Пін світла | `const int LED_PIN = D7;` |
| Стартову яскравість | `int brightness = 60;` |
| Інверсію сигналу | `const bool LED_INVERT = false;` |

Після зміни — знову натисни **Upload**.

---

## 7. Важливі особливості ESP8266 (для розуміння)

- Це **ESP8266, не ESP32** — інший синтаксис PWM і ESP-NOW, піни в D-нотації.
- `analogWrite` тут має діапазон **0–1023** (а не 0–255). У коді відсотки 0–100%
  автоматично перераховуються у 0–1023 функцією `map()`.
- Уникаємо "поганих" пінів: D0 (без PWM), D3/D4/D8 (впливають на завантаження),
  RX/TX (потрібні для прошивки), D5/D6 (зайняті під OLED). Тому й обрано **D7**.
- `yield()` у `loop()` — обов'язковий: віддає час WiFi-стеку, інакше плата зависає.

---

## 8. Швидка діагностика

Відкрий **Tools → Serial Monitor**, встав швидкість **115200**, натисни кнопку
**RST/RESET** на платі. Ти маєш побачити:
```
=== ESP8266 Light Controller ===
Точка доступу: OK
SSID: FPV-Light
IP адреса: 192.168.4.1
Веб-сервер запущено.
```
Якщо цього немає — перевір вибір плати, порт і драйвер.
