# andriy-assistant
Мій персональний AI помічник

## Парсер аукціонів UUB (`uub_parser.py`)

Маленький інструмент, що читає лот з `sale.uub.com.ua`, оцінює вигідність
і дає посилання для перевірки ринкової ціни.

```bash
pip install -r requirements.txt

# базовий аналіз
python uub_parser.py "https://sale.uub.com.ua/auction/ALE001-UA-20260611-19752/"

# з відомою ринковою ціною (грн) — точніший висновок
python uub_parser.py "<посилання>" --market 450000

# машинний вивід
python uub_parser.py "<посилання>" --json
```

Парсер пробує кілька способів зчитати дані (JSON-LD → вбудований JSON →
мета-теги → CSS), тож стійкий до дрібних змін верстки. Якщо ціна не
зчиталась — перевір селектори під актуальну структуру сторінки.
