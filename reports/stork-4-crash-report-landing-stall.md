# КРАШ-РЕПОРТ: ІНЦИДЕНТ ПІД ЧАС ПОСАДКИ STORK-4

**Об'єкт випробувань:** Безпілотний літальний апарат STORK-4
**Тематика:** Аналіз аварійної ситуації на етапі посадки, причини виникнення, вжиті дії екіпажу та коригувальні заходи
**Етап польоту:** Посадка (final approach / landing)

## 1. Загальний огляд

У цьому звіті висвітлено обставини аварійної ситуації, що сталася під час посадки STORK-4. Проаналізовано послідовність подій, що призвела до втрати швидкості нижче допустимої межі звалювання (stall speed), дії пілота щодо відновлення керованого польоту та попередні висновки щодо причин інциденту.

## 2. Опис події

Під час заходу на посадку пілот допустив зниження швидкості апарата **нижче критичної межі звалювання**. Внаслідок цього STORK-4 втратив підйомну силу на крилі, перейшов у **піке (pitch-down, різке опускання носа)** та почав некеровано знижуватися у напрямку землі.

Пілот вжив заходів з відновлення керування:

- **Повний газ (full throttle)** — для відновлення швидкості потоку та підйомної сили.
- **Набір по тангажу (pitch-up)** — спроба вивести апарат з піке підняттям носа.

> ⚠️ **ОСНОВНА ПРИЧИНА ІНЦИДЕНТУ:** > Падіння швидкості польоту нижче швидкості звалювання (stall speed) на етапі посадки. Крило втратило підйомну силу, що спричинило мимовільне піке. Подальша спроба відновлення (газ + pitch-up) є стандартною процедурою виходу зі звалювання, проте її ефективність обмежена наявним запасом висоти на етапі заходу на посадку.

## 3. Аналіз причин

| Фактор | Опис |
|---|---|
| Швидкість польоту | Знижена нижче мінімально допустимої (stall speed) під час заходу на посадку |
| Аеродинамічний стан | Втрата підйомної сили на крилі → зрив потоку → піке |
| Дії пілота | Повний газ + набір по тангажу (коректна реакція на звалювання) |
| Висота на момент звалювання | Недостатня для повного відновлення до землі (вимагає уточнення) |
| Етап польоту | Посадка — зона підвищеного ризику через малу висоту та низьку швидкість |

## 4. Попередні висновки

Звалювання на посадковій глісаді є однією з найнебезпечніших ситуацій для апарату схеми STORK через малий запас висоти для відновлення. Реакція пілота (газ + pitch-up) відповідає стандартній процедурі виведення зі звалювання, проте на низькій висоті часу й висоти для повного відновлення керованого польоту може бракувати.

## 5. Рекомендовані коригувальні заходи

- Встановити та дотримуватись **мінімальної безпечної швидкості заходу на посадку** з запасом від stall speed (контроль за телеметрією/OSD).
- Додати до передпосадкового Checklist пункт контролю швидкості на глісаді.
- Розглянути налаштування **звукового/візуального попередження про наближення до швидкості звалювання** (stall warning) в OSD/телеметрії.
- Відпрацювати відпрацювання процедури виходу зі звалювання (газ + pitch-up) на безпечній висоті під час тренувальних польотів.
- Проаналізувати лог польоту (швидкість, тангаж, висота, газ) для точного визначення висоти та швидкості в момент звалювання.
- За результатами огляду апарата — провести дефектовку та зафіксувати пошкодження (за наявності) за аналогією до розділу 2.2 звіту з першого тестового польоту.

## 6. Відкриті питання (потребують уточнення)

- Дата та місце інциденту.
- Висота над землею в момент входу у звалювання.
- Результат спроби відновлення: чи вдалося вийти з піке, чи стався контакт із землею, та масштаб пошкоджень апарата.
- Дані телеметрії/логу польоту (якщо доступні) для точного відтворення хронології.
